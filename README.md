# Betterfly Ascent

Crie uma DEMO premium da landing page da agência BETTERFLY.

IMPORTANTE:

Neste primeiro momento, desenvolva SOMENTE a landing page pública.

Não crie ainda o sistema, dashboard, banco de dados, autenticação real ou backend.

O botão "ÁREA DO CLIENTE" deve existir no header e apontar para /cliente, mas essa rota pode ter apenas um placeholder simples por enquanto.

IDENTIDADE DA MARCA

Nome: Betterfly

Paleta obrigatória:

#0B0B0B fundo principal

#F6F0EA textos e elementos claros

#BBD705 cor de destaque

A estética deve ser:

futurista, tecnológica, modernista, editorial, premium, estratégica e criativa.

Quero uma qualidade visual inspirada em sites de alto nível do Awwwards, Framer, Refokus e agências digitais contemporâneas.

Não copie nenhum site.

Use essas referências apenas como padrão de qualidade, composição, movimento, tipografia, storytelling e microinterações.

CONCEITO DA MARCA

Betterfly nasce da ideia de:

Better = melhor

Fly = voar

Use esse conceito de forma sutil na experiência do site.

A marca deve transmitir:

evolução

movimento

crescimento

transformação

ascensão

direção

ir além

Não use borboletas, asas ou elementos literais de voo.

O conceito deve aparecer principalmente através de:

animações

movimento

progressão visual

storytelling

transições

composição

copy

A sensação final deve ser:

uma agência que ajuda marcas a evoluir e chegar a um nível mais alto.

DIREÇÃO VISUAL

Predominância de #0B0B0B.

Use #F6F0EA para leitura e #BBD705 apenas como destaque estratégico.

Evite:

azul neon

cyberpunk

gradientes genéricos

excesso de glow

ícones comuns

cards SaaS genéricos

visual corporativo tradicional

Quero bastante:

tipografia grande

espaço negativo

grids sutis

linhas finas

números

labels pequenos

composição editorial

detalhes tecnológicos

microinterações sofisticadas

Tipografia sugerida:

Space Grotesk para títulos

Inter para textos e interface

ANIMAÇÕES

As animações devem ser um dos pontos fortes da experiência.

Use criatividade para implementar, quando fizer sentido:

smooth scroll

reveal de textos

stagger

parallax sutil

máscaras de imagem

scroll interactions

hover sofisticado

movimento de elementos

transições fluidas

microinterações

Tudo deve parecer premium e fluido, nunca exagerado.

Explore o conceito de evolução da marca.

REQUISITOS

Totalmente responsivo.

Mobile deve ter composição própria, não apenas desktop reduzido.

Priorize:

UI/UX

hierarquia

espaçamento

alinhamento

consistência

performance

acessibilidade

microinterações

Não use Lorem Ipsum.

Escreva textos reais em português brasileiro.

Quero que você tenha liberdade criativa para definir a melhor composição, storytelling, copy, animações e interações.

O objetivo é que a landing page pareça um projeto real de uma agência premium, misturando:

MARKETING + ESTRATÉGIA + CRIATIVIDADE + TECNOLOGIA + MOVIMENTO.

Finalize revisando toda a experiência e corrigindo desalinhamentos, excesso de texto, repetições, problemas responsivos e animações exageradas.

NÃO desenvolva o portal nesta etapa.

Apenas deixe o botão "ÁREA DO CLIENTE" e a rota /cliente preparados para a próxima fase.

Observação: Estou adicionar imagens da "historia" da betterfly, para adicionar como conteudo no website. Estou mandando também o logotipo deles ( quadrado e horizontal, ultimas imagens).
